# TO START ECHO WE NEED A VIRTUAL ENVIRONMENT FOR THIS PROJECT
# TO CREATE THAT WE NEED TO ENTER BELOW COMMANDS IN TERMINAL


# STEP 1: CREATE A VIRTUAL ENVIRONMENT USING PYTHON 3.11 VERSION
# --------------------------------------------------------------
#   WINDOWS : py -3.11 -m venv echoenv
#   MAC : python3.11 -m venv echoenv
# --------------------------------------------------------------


# STEP 2: ACTIVATE VIRTUAL ENVIRONMENT
# --------------------------------------------------------------
#   WINDOWS: echoenv\Scripts\activate
#   MAC : source echoenv/bin/activate
# --------------------------------------------------------------


# Step 3: VERIFY PYTHON VERSION
# --------------------------------------------------------------
#    COMMAND : python --VERSION
#    Output: 3.11.x
# -------------------------------------------------------------- 


#    NOTE: THE PYTHON VERSION SHOULD BE 3.11, IF IT IS 3.13 OR 3.12 THEN YOU NEED TO RE-INSTALL PYTHON 3.11



# STEP 4: INSTALL LIBRARIES
# --------------------------------------------------------------
#   COMMAND: pip install -r requirements.txt
